# Kotoba企業向け提供契約（ドラフト）

文書版: 0.1 / 作成日: 2026-10-13

本書は交渉・法務確認用の契約ドラフトであり、公開だけでは効力を生じない。
【提供者の正式名称・所在地・代表者】（以下「提供者」）と
【顧客の正式名称・所在地・代表者】（以下「顧客」）は、署名した本契約及び
[注文書・年間参加計画](order-and-participation-draft.ja.md)により契約する。

## 第1条 定義

1. 「OSS」とは、Apache-2.0その他の公開OSSライセンスで許諾されるコード・文書をいう。
2. 「契約対象提供」とは、注文書に識別子、版、範囲を記載した追加ソフトウェア、
   保守、サポート、クラウド、認証又は個別開発をいう。
3. 「追加ソフトウェア」とは、契約対象提供のうち、OSSと区別して注文書に
   非OSSと明記され、提供者に許諾権限があるソフトウェアをいう。
4. 「顧客グループ」とは、顧客の最終親会社とその支配下の法人をいう。
   支配は議決権の過半数又は契約等による経営方針の決定権で判定する。
   契約により実際に利用を許諾される法人は注文書の対象法人欄で限定する。
5. 「参加枠」とは、年間参加計画で合意したOSS支援活動又は代替資金をいう。
6. 「書面」には、署名付き電子文書及び当事者の指定窓口間の合意記録を含む。
   ただし本契約・注文書の締結には権限者の署名又は電子署名を要する。

## 第2条 成立、適用範囲及び優先順位

1. 本契約は両当事者の権限者の署名により成立し、注文書の開始日から適用する。
   OSSの取得・実行、Web閲覧、Issue又はPRの投稿だけでは成立しない。
2. OSSの利用許諾は元のOSSライセンスが優先する。本契約はOSSの利用権を制限せず、
   本契約の違反・終了によりその権利を失わせない。
3. 契約対象提供の条件は、明示的に変更条項を特定した署名済み注文書、
   個別別紙、本契約の順で適用する。DPAは個人データ処理、SLAはサービス水準に
   関して優先する。ただしOSS許諾を狭める変更は認めない。
4. 公開の方針・価格表・Web規約の更新は、締結済み条件を自動変更しない。
   注文書は適用文書の版・添付写しを特定する。

## 第3条 OSSと追加ソフトウェアの許諾

1. OSSはそのライセンスに従い利用・改変・再配布できる。企業規模やOSSの
   本番利用のみを理由に、料金、利用報告、参加又は監査義務を課さない。
2. 提供者は追加ソフトウェアについて、契約期間中、対象法人が注文書の
   用途・環境・数量の範囲で複製・実行する非独占的権利を許諾する。
   設定変更、開発・試験・災害復旧用の複製は、その範囲に含む。
3. 追加ソフトウェアの改変、ソース提供、再配布、顧客向けホスティングは、
   注文書に明記して許諾する。OSSの同じ行為にはこの制限を及ぼさない。
4. 顧客の委託先は顧客のために限り契約対象提供を利用でき、顧客がその遵守に
   責任を負う。委託先への独立した販売・再許諾権は与えない。
5. 追加ソフトウェアの利用枠の回避、他者へのアクセス資格の転売、未許諾の
   再提供を禁止する。ただし適用法上制限できない行為は除く。
   OSSの互換実装・解析・フォークを妨げる条項として用いない。
6. 商標、ロゴ、「公式」「認証済み」の表示許諾は別紙に定める。
   元のライセンスや法令で認められる出所説明まで禁止しない。

## 第4条 提供者の履行

1. 提供者は注文書の作業、期間、受入条件に従い、合理的な専門的注意をもって履行する。
2. 対応時間、対象版、修正範囲、可用性、バックアップ、復旧目標は注文書又はSLAに
   明記する。SLAがない場合、24時間対応や可用性数値を保証しない。
3. 提供者は注文書の権利台帳・配布目録を提示し、OSS・第三者コードの表示と
   必要なライセンスを配布物に含める。
4. 仕様不一致又は履行不備の通知を受けた場合、30日以内に是正又は双方合意の
   是正計画を提示する。重大な不備を是正できない場合、顧客は該当提供を解除でき、
   未履行期間に対応する前払料金の返還を受ける。

## 第5条 企業区分と料金

1. 区分は直近確定連結会計年度に基づく。Enterpriseは年間連結売上100億円以上
   又は連結従業員1,000人以上、Strategic Enterpriseは年間連結売上1兆円以上とする。
   外貨換算・対象法人・公益減免・Community向け条件は注文書に記載する。
2. 基準案はEnterpriseの年間基盤拠出額3,000,000円・参加枠20人日、
   Strategic Enterpriseは30,000,000円・100人日とする。
   基準案のみで請求せず、実際の金額は署名済み注文書による。
3. 全部又は一部の参加枠を1人日100,000円で資金に振り替えられる。
   基盤拠出額、参加振替資金、提供料金、売上連動料金は別項目とし二重計上しない。
4. 料金は税別日本円とし、適用税は別途請求する。外貨・源泉徴収・送金手数料の
   扱いは注文書に定め、必要な法定控除・証明に双方が協力する。
5. 基盤拠出額、開始時に選択した参加振替資金、固定提供料金は年額前払いを既定とし、
   請求書受領後30日以内に支払う。その他の時期は注文書に定める。
   請求争議は受領後30日以内に理由を通知し、争議のない額は期限内に支払う。
6. 成長・買収による区分変更は、通知から12か月後以降の最初の更新時に適用し、
   遡及しない。故意の虚偽申告は是正・解除の対象とするが、自動追徴の根拠としない。
   買収による対象法人の追加は区分変更とは別に、利用開始前に注文書で合意する。
7. 同じ提供範囲の更新時の基本料金・参加振替単価の増額は年5%以下とし、
   60日前までに通知する。税率変更、利用範囲拡大は区別して明示する。

## 第6条 再提供と売上連動料金

1. 追加ソフトウェア又は公式サービスを用いて、Kotobaの実行・開発機能そのものを
   第三者へ販売する場合は、対象提供、対象SKU、許諾範囲を再提供別紙に定める。
2. 別紙で合意した場合に限り、対象純売上の1%を追加料金とする。純売上は
   該当売上から間接税・実際の返金を控除した額とし、セット販売の配賦方法、
   対象地域、集計期間、年額上限を別紙に確定する。
3. 顧客は各四半期終了後30日以内に集計報告する。提供者は報告に基づき請求し、
   顧客は受領後30日以内に支払う。上限の残額まで請求し、超過分は請求しない。
4. OSSだけの再提供、Kotobaで開発した一般アプリ、顧客全体の売上は対象外とする。
   再提供別紙がなければ、売上連動料金の支払義務はない。

## 第7条 OSS参加

1. Enterprise及びStrategic Enterpriseは、注文書の年間参加計画を履行する。
   活動、資金又は混合を選べる。Communityには必須参加枠を課さない。
2. 活動は担当者・メンテナーの事前承諾、範囲、確認資料、品質基準、充当上限を
   計画に定める。1人日は8時間とし、機器・CI資源は合意した換算額で充当する。
3. PRのマージや採用を達成条件にしない。事前合意した作業の履行と成果の
   品質で確認し、顧客に採用・仕様決定・メンテナー権限を与えない。
4. 顧客の機密コード、営業秘密、個人データの公開は義務にしない。
   公開できない活動は公開可能な別作業又は資金へ振り替える。
5. 年度末の未達枠は計画の手続により確定し、1人日100,000円で資金に振り替える。
   活動未達に関する金銭的救済は当該未達枠の振替額を上限とし、懲罰的請求はしない。
6. 年度途中で本契約が終了した場合、参加枠は経過日数で按分し、確認済み活動・
   資源を先に充当し、残枠に必要な資金を支払済み参加資金から充当する。
   充当後の過払参加資金は年間参加計画の算式で返還する。活動・資源そのものの
   費用を金銭で払い戻す義務はない。

## 第8条 知的財産と貢献

1. 既存コードの権利は元の権利者に残る。顧客のコード・データ・生成物は、
   第三者の権利を除き顧客又はその権利者に帰属する。
2. 公開OSSへの貢献は当該OSSのライセンスで受け入れる。顧客は投稿者の権限、
   雇用主・第三者の承諾を確認し、必要な権利表示を行う。
3. 本契約だけでは著作権譲渡、独占許諾、将来の非OSS再許諾権を取得しない。
   個別開発の成果物については、既存部分と新規部分を分け、作業開始前に
   利用許諾・所有・公開可否を注文書又は作業別紙で確定する。
4. 企業向け提供に関する知的財産権侵害の申立ては速やかに通知し、双方で
   証拠保全・解決に協力する。訴訟防御・補償を約束する場合は対象、除外、
   上限、防御権限を別紙に明示する。自動的な無制限補償は設けない。

## 第9条 秘密保持とデータ処理

1. 秘密と表示された情報又は性質上秘密と合理的に分かる情報を、契約履行以外に
   利用・開示しない。必要な従業員・委託先には同等の義務を課す。
2. 公知、適法な既知・第三者取得、独自開発の情報は除く。法令による開示は、
   許される限り事前通知し、必要な範囲に限定する。
3. 秘密保持義務は終了後3年間、営業秘密は法令上営業秘密として保護される間存続する。
   個人データの保護・利用制限は、当該データを保有する間、DPA及び適用法に従い存続する。
4. 顧客データは注文書で定める履行目的に限り取り扱う。学習用途・広告用途・
   販売用途への利用は、別途の明示的な合意がなければ行わない。
5. 個人データを扱う提供は、目的、役割、所在地、再委託、越境移転、保全、
   漏えい通知、削除・返還を定めたDPAを開始前に締結する。DPAが未締結なら、
   当該個人データを受け入れない。DPAへの合意はOSS自己運用の条件ではない。

## 第10条 報告・確認と資金使途

1. 顧客は契約開始・更新時の区分自己申告、年間参加記録、合意した売上報告を行う。
   OSSのみの利用実態を追跡・報告させない。
2. 重大な不整合の合理的根拠がある場合、提供者は理由を書面通知して、契約対象の
   区分・請求・参加の確認に必要な資料を求められる。通常は年1回以下、30日前通知とし、
   守秘義務を負う独立専門家による限定確認を優先する。顧客の本番環境・業務コード・
   認証情報への直接アクセスを要求しない。確認費用は提供者が負担する。
3. 提供者は基盤拠出・参加資金を区分記録し、提供者の会計年度終了後120日以内に使途・
   成果・繰越残高の集計報告を公開する。専用開発・一般サポート等と区別する。
   顧客名・個別金額・機密活動を公開する場合は事前承諾を得る。
   年間参加計画の精算が未確定の分はその旨を明示し、確定後の報告に反映する。
4. 未使用の共通基盤資金は保守・運営準備金として繰り越す。企業固有の
   技術判断への支配権や個別成果の所有権は発生しない。

## 第11条 保証と責任

1. 提供者は契約対象提供を許諾・提供する権限を有すること、及び第4条の
   合理的な専門的注意をもって履行することを保証する。
   OSS自体の保証・責任は元のライセンスによる。提供者が独自に引き受けた保証・
   責任をOSSの貢献者に負わせず、Apache-2.0第9条に従う。
2. 注文書で明示したものを除き、特定目的への適合、無停止、全ての不具合の修正、
   将来機能の実装を保証しない。
3. 各当事者の本契約に関する損害賠償は、通常かつ直接の損害に限り、
   原因発生前12か月に該当注文書について支払われた又は支払期限が到来した
   料金の合計を総額上限とする。未払料金、返金、参加枠の振替精算は、この
   損害賠償上限で減額しない。別紙補償は明記した上限・範囲に従う。
4. 故意・重過失、又は強行法規上制限できない責任には前項の制限を適用しない。
   個人データ・秘密保持の追加上限が必要な場合は、DPA又は注文書で確定する。

## 第12条 期間、停止、解除と移行

1. 期間は注文書による。既定は12か月、自動更新なし。更新には双方の書面合意を要する。
2. 重大な違反について書面通知後30日以内に是正されない場合、相手方は
   該当提供を停止・解除できる。争議中の料金は第5条の手続で協議する。
3. 差し迫ったセキュリティ侵害又は法令上の必要がある場合、提供者は必要最小限の
   範囲で緊急停止でき、理由・範囲・復旧条件を速やかに通知する。
   OSSのローカル実行を遠隔停止する権限は与えない。
4. 契約終了後90日間、顧客は既に納品された追加ソフトウェアを既存業務の移行目的で
   継続使用できる。新規販売・新規展開には使わない。元の範囲内のこの利用に
   新たな許諾料金を課さない。違法利用又は継続が重大な安全上の危険を生む場合は除く。
5. クラウドの移行期間、利用料、データ出力形式は注文書に定める。既定は終了後
   30日間の出力受付とし、通常形式のデータ出力に追加料金を課さない。
   独自変換・継続ホスティングは書面で合意する。
6. 出力受付終了後30日以内に顧客データを削除し、必要な保持・バックアップの
   消去期限を注文書又はDPAに定める。法定保持分は隔離・利用制限する。
7. 提供者の履行不能・重大な違反による解除は未履行期間の前払金を返還する。
   その他の終了では既履行の基盤拠出・提供料金は返還しない。
   参加資金は第7条の按分規則による。任意の中途解約は注文書に定めた場合に認める。
8. 移行期間終了後、追加ソフトウェアの利用・複製を終了する。法令・証拠保全上の
   必要な保管用複製は実行せず保持できる。OSSの権利・利用は引き続き元の条件による。

## 第13条 一般条項

1. 通知は注文書の指定窓口へ送り、到達を確認できる方法による。
2. 再委託しても提供者は履行責任を負う。契約の第三者への譲渡は相手方の書面承諾を
   要する。組織再編時の対象法人・区分は第5条に従い確認する。
3. 不可抗力では速やかに通知し影響軽減に努める。30日を超えて重要な提供が
   継続不能なら、顧客は該当提供を解除し未履行期間の前払金の返還を受ける。
4. 準拠法の案は日本法、第一審の専属的合意管轄の案は東京地方裁判所とする。
   当事者・取引地域に応じて法務確認し、署名する注文書で最終確定する。
5. 契約の変更は双方の書面合意による。一部条項が無効でもその他は存続する。
   本契約と署名済み別紙は契約対象提供についての完全な合意を構成する。
6. OSS許諾、未払金・精算、知的財産、秘密保持、データ削除、責任、紛争処理は
   その性質・定めた期間に従い終了後も存続する。
