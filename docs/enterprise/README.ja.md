# Kotoba OSS・企業向け提供の文書

作成日: 2026-10-13 / 文書版: 0.1

KotobaのOSS部分はApache-2.0を維持する。企業の規模、売上、利用目的を理由に、
OSSだけの利用へ追加の支払い・登録・活動義務を課さない。企業向け提供を契約する
大企業には、契約料金に加えて、OSSの保守を育てる活動またはその代替資金を求める。

| 文書 | 用途 | 状態 |
|---|---|---|
| [ライセンス・企業向け提供方針](licensing-policy.ja.md) | OSSと企業契約の境界、対象企業、料金、資金運営 | 採用する設計方針 |
| [企業向け契約ドラフト](enterprise-agreement-draft.ja.md) | 利用許諾、料金、責任、終了、紛争処理 | 交渉・法務確認用ドラフト |
| [注文書・年間参加計画](order-and-participation-draft.ja.md) | 提供物、金額、活動、成果確認を確定 | 記入用ドラフト |

## 文書の効力

この文書群を読むこと、Kotobaをダウンロードすること、OSSを本番利用することは、
企業向け契約への同意を意味しない。企業契約は、権限を持つ当事者が契約と注文書を
書面または電子署名で締結して成立する。既存の[LICENSE](../../LICENSE)と
[NOTICE](../../NOTICE)は変更しない。第三者のコードには各権利者のライセンスが適用される。

料金は契約設計上の基準案であり、販売開始、契約成立、請求、SLAの提供開始を
示すものではない。提供主体、対象製品、履行能力、税務、責任条件を確認し、
注文書の必須欄を確定してから利用する。契約本文の空欄は署名前に解消する。

## 契約までの流れ

1. OSSだけで足りるか、追加サービス・追加機能が必要かを確認する。
2. 必要な提供物とその権利区分を注文書に列挙する。
3. 契約する企業グループの区分、年額、参加方式を確定する。
4. 提供責任者、保守範囲、データ処理、終了時の移行条件を確定する。
5. 契約と注文書を締結し、提供・活動・資金使途を記録する。

## 典型例

| 利用 | 料金・参加義務 |
|---|---|
| Big TechがApache版をフォークして社内本番利用 | OSSの条件のみ。企業契約不要 |
| 大企業がApache版で顧客向けSaaSを運営 | OSSの条件のみ。売上連動料金なし |
| 大企業が公式の長期保守・追加管理機能を契約 | 注文書の料金と参加義務あり |
| 大企業が契約対象の追加機能を組み込んだKotoba開発サービスを販売 | 再提供許諾と売上連動別紙を締結 |
| 小企業がOSSを利用 | 無料。登録・活動義務なし |
| 小企業が有料サポートを希望 | 別見積り。大企業向けの必須参加枠は適用しない |
| 契約終了後にApache版へ移行 | OSSの権利を継続。契約対象の追加機能・サービスは終了条項による |

契約・スポンサー料は、技術判断やマージ権限を購入するものではない。
技術上の意思決定は既存の[GOVERNANCE](../../GOVERNANCE.md)による。
