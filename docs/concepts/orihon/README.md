# 折本 — OS UI/UX 独立コンセプト（JUN-566）

## 核となる考え

表紙付きの折本から、**用事を一冊の作業帳、画面をその頁、作業間の関係を折り目**として扱う。表紙は境界と再開地点、蛇腹は前後の文脈を残した移動、折り目は関連する資料や別アプリへの接続を表す。紙を模倣するだけでなく、折りたたんだ状態と展開した状態の両方で操作できる。既存のnative desktopとは別案であり、採用・置換を決めたものではない。

## 情報と操作

- **表紙**: 作業帳名、前回の場所、未完了の作業。閉じると内容を隠し、次回は最後の頁を開く。ロックとは別で、表紙を閉じても機密保護を保証しない。
- **頁**: 今日、作業、関連資料、履歴などを並べる。選択中の頁を正面に、前後は周辺視野に置く。頁はメモ・ファイル・アプリのビューを参照し、データ自体を複製しない。
- **折り目**: 文脈上の資料やアプリを差し込む入口。戻ると挿入前の頁と位置を保つ。長い作業はグループ化して畳める。削除・並べ替えは明示操作で、折りたたみは削除ではない。
- **複数の作業帳**: タスク単位で切り替え、別の帳の頁を参照できる。履歴はローカルの時系列で開き直せる。保存・復元・破棄の状態を表紙と頁上で明示する。
- **同意**: 外部操作は選択中の頁から独立した読みやすい確認面を開き、接続先、操作、送るデータと許可／拒否を示す。新鮮な本人の選択を操作ごとに要求し、否認では送信しない。確認面を折り目やアニメーションに隠さない。共通クライアントランタイム契約に従う。

## 操作と感覚

クリック／タップで頁を選択、折り目で次へ。左右キーで頁移動、Escで表紙、Tabで各操作を巡る。狭い画面では横方向の頁列をスクロールし、頁ナビゲーションを常時使えるようにする。決定や移動には短い、任意の音を想定し、初期は無音。紙の折れや小さな慣性は状態変化を伝える範囲に留め、reduced motionでは即時切替。高コントラスト、文字拡大、スクリーンリーダー、キーボード単独操作を受入条件とする。

## 画面モデル

| 状態 | 見えるもの | 主要操作 |
| --- | --- | --- |
| 閉じた表紙 | 作業帳の名前と再開 | ひらく、作業帳を切替 |
| 部分展開 | 今の頁、左右の隣接頁、折り目 | 頁を移動、挿入、戻る |
| 広げて俯瞰 | 頁の順番とグループ | 並べ替え、別帳へ移動 |
| 確認 | 接続先、操作、データ、許可／拒否 | 今回だけ許可、拒否 |

## 実装境界と未決

`index.html` は依存・通信なしの静的な操作試作で、実OS、データ永続化、複数作業帳、外部操作、保存・復元や同意ブローカーは未接続。固定サンプルで概念を示す。現行の native Kotoba/Amu GUI は HTML/CSS ベースの完成ブラウザではないため、この HTML はデザイン検討用であり実装方式の決定ではない。将来のnativeレンダラ／共有 Browser への反映は別途設計・資格化する。段階的に、情報構造と操作の有用性、頁数増加、文書編集、同意面、低スペック時の性能、実機・支援技術を検証する。
