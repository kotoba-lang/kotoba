# Oracle run: dapps-ui Hiccup + Garden twins (AWAI-2793)

Date: 2026-11-11. A one-shot local reference run, not CI, not a gate and not a
build step; the CDCI rule (no JVM/nbb in CI/CD) is unchanged, and the oracle
`cljc`/`hiccup`/`garden` files never enter a gate, workflow, build,
packaging or execution path. Native results must never fall back to this.

It shows what hosted `.cljc` dialects read from the three session UI
documents added for AWAI-2793 (sound/display/soshiki): the Hiccup facts
rendered by the real `hiccup` library and the style data compiled by the
real `garden` library on the JVM, plus the Babashka structural test that
pins the facts to the `.kotoba` documents case for case.

## Commands (from the kotoba worktree root)

    cd oracle/dapps-ui && bb -cp src:test test/itonami_dapps_ui_test.clj

    cd oracle/dapps-ui && clojure -Sdeps '{:paths ["src"] :deps {hiccup/hiccup {:mvn/version "1.0.5"} garden/garden {:mvn/version "1.3.10"}}}' -M render.clj
