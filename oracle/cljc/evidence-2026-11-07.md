# Measurements, 2026-11-07 (AWAI-178)

One-off oracle measurements on Apple Silicon macOS. They are not a gate and not a proof that
any native implementation is correct.

- **Tools:** OpenJDK 21.0.1, Clojure 1.12.0 (CLI 1.12.5.1654), nbb 1.4.208, Babashka 1.12.218,
  Node.js 26.0.0.
- **Sandbox:** the JVM and nbb load runs used `sandbox-exec` with the network and writes
  outside the scratch directory denied.
- **Input:** `kotoba-lang/kotoba` `91ed14c09` plus this change. Awai and Itonami sources were
  local checkouts, some older than their remotes.
