# Sumitsubo CAD

Cleanroom CAD geometry, open-format import/export, and published-API-shape
adapters. The canonical library identity and capability matrix are in
[`library.edn`](library.edn); repository boundaries are in
[`repository-contracts.edn`](repository-contracts.edn).

```ts
import { createDrawing, exportDxf } from "@etzhayyim/sumitsubo-cad";
```
