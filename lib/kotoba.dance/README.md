# kotoba-lang/dance

**SSoT for `kami.dance`** — VRM dance stage as pure CLJ/EDN frame-ir projected for
`kami.webgpu` / `kami.webgl`. Pure `.cljc` (no GPU, no mesh loader).

`kotoba.dance` is a thin facade. Live consumer: `network-isekai` stage (`kami.dance`).

See ADR-2607102200 addendum 6.
