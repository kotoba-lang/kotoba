# Code of Conduct

This project uses the Contributor Covenant Code of Conduct, version 2.1.

## Our Standards

Participants should communicate respectfully, assume good intent when possible,
and focus disagreement on facts, design, safety and scope (what this actor is
and is not allowed to fetch/ingest).

Unacceptable behavior includes harassment, threats, discrimination, publishing
private information, or using the project to crawl/ingest domains outside its
configured seed list.

## Enforcement

Maintainers may remove comments, reject contributions or restrict
participation when behavior puts contributors, users, operators, net-kotobase,
or the domains this actor is allowed to touch at risk.

Report conduct concerns privately to the maintainers through the kotoba-lang
organization.
