# org.ietf.xwing — X-Wing hybrid KEM in native .kotoba

[X-Wing](https://datatracker.ietf.org/doc/draft-connolly-cfrg-xwing-kem/) is the
general-purpose X25519 + ML-KEM-768 hybrid KEM of the IETF CFRG draft
`draft-connolly-cfrg-xwing-kem`. `kotoba/xwing/core.kotoba` (`ns xwing.core`) implements
it on this repository's native ML-KEM-768 (`gov.nist.mlKem`), X25519 (`org.ietf.x25519`)
and SHA-3 (`gov.nist.sha3`). Bytes are `:vector-i64` of 0..255. It is the hybrid KEM
chosen for AWAI-102 and JUN-352: a published construction with a security analysis,
rather than an in-house combiner.

| function | result |
|---|---|
| `public-key sk` | pk (1216) = ML-KEM ek (1184) ++ X25519 public (32); `sk` is the 32-byte seed |
| `encapsulate pk eseed` | ss (32) ++ ct (1120); `eseed` is the caller's 64 bytes of randomness |
| `decapsulate sk ct` | ss (32) |

`ss = SHA3-256(ss_M || ss_X || ct_X || pk_X || "\./" "/^\")`, with the seed expanded by
SHAKE256 to the ML-KEM `d`, `z` and the X25519 secret. Wrong lengths, values that are not
bytes and an ML-KEM key that fails FIPS 203 section 7.2 give an empty vector. As the draft
specifies, a low-order X25519 value is not refused, and a changed ciphertext decapsulates
to another secret (ML-KEM implicit rejection).

## Native gate

`kotoba/xwing/native_gate.kotoba` is generated by `tools/gen_gate.py` from the draft's own
test vectors (`test/test-vectors.json`, see `test/PROVENANCE.md`); it holds no strings. An
image holds only 10-20 X25519 multiplications, so each vector is a group:

| group | pass | checks |
|---|---|---|
| `group-a` | 7 | vector 0: public key, encapsulation (ss and ct), decapsulation |
| `group-b` | 7 | vector 1, the same |
| `group-c` | 63 | vector 2, the same; a changed ML-KEM or X25519 ciphertext byte gives another secret; refusals |

Built as modules and measured 2026-10-30 on Apple M1 Max with the Amu Mac root of main
`91faa123`:

| image set | change | a / b / c |
|---|---|---|
| gate | none | **7 / 7 / 63** |
| ctl-label | last label byte changed | 1 / 1 / 57 |
| ctl-order | X25519 secret before the ML-KEM secret | 1 / 1 / 57 |
| ctl-nopkx | X25519 public key left out of the combiner | 1 / 1 / 57 |
| ctl-eseed | X25519 ephemeral taken from the ML-KEM half of eseed | 5 / 5 / 61 |

`scripts/check-pq-native.py` runs the gate and these mutants in CI (Linux arm64).

## Non-claims

- **A draft, not an RFC.** The construction and vectors follow the draft at reference
  commit `984c2f7a`; a later revision could change them.
- **Not constant time**, and no random source: the caller supplies `sk` and `eseed`.
- No x86_64 run yet.
