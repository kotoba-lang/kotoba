# ADR 0001: N-Quads serialization is sovereign Kotoba

`src/n_quads.kotoba` is the sole production language source. JVM Clojure is a
compiler/test host only and is not a production runtime.

The serializer accepts canonical bounded `:document` RDF terms and a document
vector of at most 32 quads. String replacement is literal, rejects an empty
needle, and every intermediate/result string remains within the compiler's
64 KiB UTF-8 value budget. Unknown term kinds and missing required members fail
closed. The program declares no effects.

Conformance compares observable output and rejection behavior across reference
execution, restricted JavaScript, and instantiated typed Wasm. Generated byte
identity is not a language-compatibility requirement; hashes remain useful only
for artifact integrity and provenance.
