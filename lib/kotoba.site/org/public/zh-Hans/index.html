安装

brew tap kotoba-lang/kotoba && brew trust kotoba-lang/kotoba && brew install kotoba

一行 Homebrew 安装。然后在本地运行 kotoba selfhost check --json。

Kotoba — 用于 AI 生成软件的安全快速语言

Kotoba 设计用于安全、超快的 AI 生成软件。探索语言、可复现基准及 Kotobase 和 Kotoba Cloud 堆栈。
