इंस्टॉल

brew tap kotoba-lang/kotoba && brew trust kotoba-lang/kotoba && brew install kotoba

एक-पंक्ति Homebrew इंस्टॉल। फिर स्थानीय रूप से kotoba selfhost check --json चलाएँ।

Play

डाइजेस्ट-बाउंड डेमो आर्टिफैक्ट: ब्राउज़र 344 बाइट लाता है, SHA-256 जाँचता है, import अस्वीकार करता है, main() चलाता है। अपेक्षित 42। यह इन-ब्राउज़र कंपाइलर नहीं है।

तैयार। अभी कोई कोड नहीं चला।

इंटरैक्टिव wasm-webcomponent डेमो (कंपाइलर नहीं): solar-helix · kami-survivors · gpu-clear

सुरक्षित कोड। मशीन गति के लिए निर्मित।

Kotoba — AI-जनित सॉफ़्टवेयर के लिए सुरक्षित, तेज़ भाषा

Kotoba सुरक्षित, अल्ट्रा-तेज़ AI-जनित सॉफ़्टवेयर के लिए डिज़ाइन किया गया है। भाषा, पुनरुत्पादनीय बेंचमार्क, और Kotobase और Kotoba Cloud स्टैक का अन्वेषण करें।

  • कोई परिवेशीय अधिकार नहीं
  • संकीर्ण रूप से अनुमति दें, फिर संकलित करें
