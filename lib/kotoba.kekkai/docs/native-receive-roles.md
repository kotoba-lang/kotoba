The role-aware receive fixture executes the same production receiver and
native kernel for both Noise roles under the explicit main-derived efec
compiler profile. Product source, real runtime, code/stack/grant bounds and
original1MiB/2048-part/128-assembly/4MiB limits remain unchanged.

UDP packets:2081 protocol packets and3 empty, immutable-schedule test triggers.
Each trigger only lets the test NIC fixture emit an actual first Noise
message to its fixed peer endpoint. The peer compares the entire initial
wire, then supplies the independently generated real response. A trigger
does not fabricate authentication, feed an alleged event to the production
receiver, authorize an application or supply a consent choice.

perform a same-peer/key/epoch/time fresh-channel transition and reconstruct

packet classifications are derived from the fixed schedule, distinct from
native NIC RX/release counters and actual wire-byte comparisons.
