MailA2A Binding 1.0

Status: Experimental community specification.

This stable URI identifies the store-and-forward email custom binding for A2A v1.0. It maps A2A operations and ordered task events onto RFC 5322 threads and MIME parts, carries exact x402 v2 objects in protected JSON, and profiles S/MIME/OpenPGP for direct messages and RFC 9420 MLS for private groups.
