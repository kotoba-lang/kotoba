MailA2A

A store-and-forward email binding for A2A v1.0, with x402 v2 payment objects and MLS-protected groups.

Binding 1.0 · Source and reference validator

Reuse, do not replace

RFC 5322 and MIME package messages. A2A supplies task semantics. x402 supplies payment objects. S/MIME or OpenPGP/MIME secures direct mail. RFC 9420 MLS secures groups.
