# Changelog

All notable changes to `kotoba-lang/tex` are documented here.

## [0.1.0] - 2026-07-01

Initial release.

- `kotoba.lang.tex.core`: EDN-first LaTeX document generator.
  - `render`, `escape`, `raw` — core rendering and escaping.
  - `command`, `env` — generic escape hatches.
  - `document`, `section`, `subsection`, `subsubsection`, `item`, `itemize`,
    `enumerate`, `math`, `display-math`, `frac`, `sqrt`, `tabular` —
    document-building helpers.
