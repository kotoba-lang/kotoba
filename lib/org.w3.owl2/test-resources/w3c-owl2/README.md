# W3C OWL 2 conformance test cases -- profile RL

`profile-RL.rdf` is the W3C OWL Working Group's export of every
non-rejected OWL 2 test case tagged profile RL, copied byte for byte from

    https://www.w3.org/2009/11/owl-test/profile-RL.rdf
    retrieved 2026-09-25
    sha256 6415369555af022fedd0fe9a7d6b56eb274f89284e4109d7303540ec75c76988

It is redistributed unmodified, for testing, under the terms W3C applies to
material on its site (https://www.w3.org/copyright/). It is read only by
`test/owl/w3c_rl_test.cljk`; nothing under `src/` depends on it.
