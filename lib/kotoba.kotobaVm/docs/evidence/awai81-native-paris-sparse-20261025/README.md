# AWAI-81 native Paris sparse-frame follow-on

This is a bounded experimental native candidate, not a Paris conformance certificate or a production selection. The pinned `ethereum/tests` v13.3 Paris corpus has 19,807 full-state cases. The same-ELF v45 census attempted every case. The audited result is 19,799 passes, three native frame-step policy refusals (00596–00598), five host wall-time failures (05687–05689, 10327, 10540), zero semantic/gasUsed mismatches among passes, and zero missing or duplicate IDs. See `full-v45-audit.json`, `full-v45-config.json` and the exact orchestration source `full-v45-runner.py`. The 997 batch receipts include exactly five abnormal exits, corresponding to the five wall-time cases. The complete result and batch files remain in the task workspace; their SHA-256 collection digests are in the audit. `receipt.json` records the earlier selected gates and individual official cases.

The executor now keeps EVM memory and calldata logical lengths separately from their materialized byte prefixes. Memory expansion charges gas and enforces the 32 MiB profile limit without allocating zero-filled bytes at each nested call. Reads retain EVM zero-padding; writes materialize only the necessary prefix. Child frames through depth three own region buffers, and CALL targets are truncated to 160 bits before precompile classification. These changes address a native trap in deep `STATICCALL` case 12396 and preserve the selected CALL/CREATE/transaction/state-root path.

The R2 and R3 Amu compiler images are byte-identical. Module and pack compilation for every listed v45 artifact used R2; source locks and ELF hashes are in `receipt.json`. The isolated execution has no network, an empty `PATH`, and native Kotoba code only. Gate counts are exact assertion totals, not corpus case counts. The live-domain receipt covers four local replicas and certified checkpoint extension; the durable-store receipt covers process crashes, restart, lock competition, stale/fork refusal, retry, and corruption. Physical power loss and a public voting fleet have not been qualified.

Official cases 12398 and 12399 pass on v45 with exact corpus rows. The v45 10327 and 05687 targeted retries also exceeded 45 minutes at 6 GiB and a 64 MiB stack; the exact-input receipts are `target-10327-v45-timeout.json` and `target-05687-v45-timeout.json`. No target container remained after timeout. Earlier targeted inputs for 12398/12399 accidentally had terminal newlines, which the driver interpreted as empty additional rows and trapped after writing valid results; those receipts are invalid diagnostic evidence. Keep the PR draft and AWAI-81 In Progress until the eight non-passing official cases, wider resource envelope, and public runtime are qualified.

The full-run auditor at `test/kotoba/vm/evm/audit_paris_full.py` reads the pinned manifest, the exact ELF, case result files, host failure receipts and batch exits. Run it with the scratch `paris-full` directory and version `v45`. A native `~pass` row for a valid transaction must contain the official state root and logs hash; a manifest transaction exception must carry native rejection status 11. The auditor also compares every passed case's gasUsed against the pinned official BlockchainTests projection; a rejected transaction has the matching exception and zero gasUsed. It separates policy refusals in result files from semantic mismatches and host failures, reports missing and overlapping case IDs, and hashes the result, failure and batch-receipt sets for reproducibility. Results from distinct ELF versions or resource profiles are not combined into a full-conformance claim.

The runner used three native workers at 2 GiB and an 8 MiB stack each. It allowed 600 seconds without a new case result and 2,700 seconds for the slower suites and selected stack/diffplaces cases. The runner's live progress count includes a written `~fail` file; the independent auditor is the source of the 19,799 pass count. The copied runner is a source snapshot tied to the scratch directory layout, not an installed production command.
