# Production signer set fixtures (JUN-813, ADR-0286 amendment 7)

PUBLIC data only. The signer set is **verification-only**: all three slots live on one Mac under `~/.itonami/aiueos-signers/`, which gives no custody
separation (see the ADR). No seed, private key or passphrase is, or may be, in this directory.

- `prod-pubkeys.json` the three slots' public keys (Ed25519 32 bytes, ML-DSA-65 1952 bytes, hex) and their sha256 fingerprints. The kernel module
  `kotoba/aiueos/imgsig_prodkeys.kotoba` is generated from it: `python3 scripts/aiueos-signer.py emit-pinned --from fixtures/signers/prod-pubkeys.json --out kotoba/aiueos/imgsig_prodkeys.kotoba`.
- `golden/` one header of each object kind, signed ONCE with the real slots (stored without the all-zero tail of the 16384-byte header, so 6912 bytes =
  128 + 2 x 3392), and `golden.json`, the record of what each covers. The image (5000 bytes) and the catalog body are not stored: they are regenerated by
  `scripts/prodsig_oracle.py` from fixed rules, and the headers' manifests are checked against them.

| file | kind | slots | covers |
| -- | -- | -- | -- |
| `aiueimg2.header` | AIUEIMG2, version 5 | 0, 1 | the 5000-byte fixture image of `update2_oracle.image()` |
| `aiuecat1.header` | AIUECAT1, version 7 | 1, 2 | the three-entry catalog body of `prodsig_oracle.golden_inputs()` |
| `aiuefrs1.header` | AIUEFRS1, version 7 | 0, 2 | issued 2026-11-06T00:00:00Z, valid 30 days, channel 1 |

How they were made (run once, on the Mac that holds the slots; CI never needs the seeds):

    python3 scripts/prodsig_oracle.py inputs DIR
    python3 scripts/aiueos-signer.py sign-image   --version 5 --slots 0,1 --out DIR/img.signed DIR/golden-image.bin
    python3 scripts/aiueos-signer.py sign-catalog --version 7 --slots 1,2 --out DIR/cat.signed DIR/golden-catalog.body
    python3 scripts/aiueos-signer.py sign-fresh   --version 7 --issued 1793923200 --valid-until 1796515200 --slots 0,2 --out DIR/frs.signed
    head -c 6912 DIR/img.signed > golden/aiueimg2.header     # likewise cat.signed and frs.signed

Replacing the signer set (rotation) re-signs these three once; the gate's refused cases are derived from them on the host and follow.
