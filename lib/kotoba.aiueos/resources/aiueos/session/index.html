今日のシェル

          
ホストされた aiueos セッションです。CID は https://kotobase.net から、推論は murakumo-main 経由で、この文書のボタンがセッション過程に頼んで動かします。 `kbb -M:cloud-live check` は別の CLI で、この gate ではありません。

          

            
kotobase を読む

            
既定 CID は空バイト列の raw CIDv1。ゲートウェイが 200 と 0 バイトを返し、セッションがハッシュを CID と突き合わせます。

この機械を追加

          
Passkey をこの画面で使うか、スマホでコードを読み取ります。どちらも同じアカウント確認を通り、Passkey の秘密鍵は Node へコピーしません。

          

            
Passkey で続ける

            
この機械の Kotoba Browser から、auth.kotoba.cloud の Passkey を確認します。

            
          

          
スマホで続ける
スマホ側でも Passkey を確認してから、この機械を承認します。表示する承認URLにアカウント鍵や端末トークンは含めません。
