# ADR-0228 — Hankaku/Zenkaku switches the guest desktop's IME off and on

Date: 2026-09-24

## Status

Accepted. Closes the `:ime-toggle` floor of the ADR-0226 ladder.

**Green only when** `kbb --backend sci --classpath src scripts/compositor-guest.cljk guest-browser-ime-toggle`
(`AIUEOS_GUEST_BROWSER=1`) prints `AIUEOS_COMPOSITOR_GUEST_BROWSER_IME_TOGGLE_OK`:
after ADR-0227's preedit commit, the host types Hankaku/Zenkaku, `k a`,
Hankaku/Zenkaku, `k a`, Enter. The first toggle turns the IME off, so `k a`
reaches window 1's body as latin; the second turns it on, so `k a` Enter
commits か. Serial:
`AIUEOS_GUEST_BROWSER_IME_TOGGLE_OK presses=7 off=0 latin=2 committed=1 ime=1 ops=67 text-px=1189 hash=4aaf87ee`.

Not: an on-screen IME indicator (`:no-ime-indicator`), a per-window IME
state, or a composition that survives the switch.

## Decision

1. **The toggle is a Kotoba decision** (`browser-ime.kotoba`). Evdev 41 flips
   word 432 in either state and discards whatever was being composed (romaji,
   preedit, conversion); it returns 0. ADR-0225 made the IME-off path but no
   key reached it.
2. **Oracle.** The hosted `aiueos.compositor.ime/handle-key` has no toggle
   key. The hosted desktop switches with `aiueos.compositor.desktop/set-ime`,
   which clears `:buf`, `:preedit` and the conversion. The seven new
   `browser-ime-v1` vectors were generated by feeding `handle-key` and, at
   the toggle, that same `set-ime` assoc with the flipped state. They also
   assert word 432.
3. **Evdev 41** is `KEY_GRAVE`. On a JIS keyboard the Linux AT driver
   delivers Hankaku/Zenkaku as this code (`KEY_ZENKAKUHANKAKU`, 85, is the
   HID route). The QMP injector sends qcode `grave_accent`.
4. **C decides nothing.** IME_TOGGLE_GO takes 7 presses through
   `kotoba_aiueos_browser_key`. It counts latin and kana by the object's
   word 432 after each key, and compares each answer with the vectors'
   0 1 1 0 0 0 1. Then it presents and takes a census.
