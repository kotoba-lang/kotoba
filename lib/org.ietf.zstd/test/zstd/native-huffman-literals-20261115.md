# Native four-stream Huffman literals, 2026-11-15

`zstd.huffman-literals/decode-four` builds a bounded prefix table from a completed tree, validates jump lengths, and reads four independent reverse streams with exact end checks. It is a focused component and is not yet wired into the Forest frame decoder; direct-weight trees, treeless reuse, one-stream literals and full frame handling are outside this test.

The existing Otehon Prolly leaf fixture has a 258-byte compressed literal section with 270 regenerated bytes. Invalid jump lengths, a missing stream marker, truncated FSE input and a missing Pack are refused.
