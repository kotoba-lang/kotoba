# oidc

OpenID Connect substrate: nonce/state, issuer/audience constraints, ID-token
verification result shape, and userinfo host port.

For the raw OpenID Connect Core spec-as-data substrate (zero deps, no host
assumptions), see [kotoba-lang/org-openid-oidc](https://github.com/kotoba-lang/org-openid-oidc).
This repo is the result-shape/substrate layer consumed by
[kotoba-lang/authentication](https://github.com/kotoba-lang/authentication).
