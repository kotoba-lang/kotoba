# moyai-ledger

Actor-neutral, append-only, non-monetary, non-transferable, decaying reciprocity-credit ledger.

Canonical repository metadata is `library.edn`. Run `./run_tests.sh` from a standalone checkout.

Canonical repository: `kotoba-lang/moyai-ledger`. Historical alias:
`etzhayyim/com-etzhayyim-moyai-ledger` (GitHub redirect). This is a reusable
subject-plane library, not an executable actor, so it intentionally has no
`actor-` or `lib-` prefix.
