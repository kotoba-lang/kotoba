# kotoba-lang/tilemap

Safety-first tilemap domain interpreter written in sovereign `.kotoba` source.
It was restored from the legacy `kami-engine/kami-tilemap` Rust crate and is
compiled by `kotoba-lang/compiler`; JVM Clojure is used only as a test host.

KAMI Tilemap: 2D tile layers, collision map, world/tile coordinate
conversion, and GPU instance-buffer data generation for RPG/platformer/
strategy games. Tile rendering, WebGPU, shaders, devices, 3D and physics stay
behind capability-gated Kami providers. This package owns only persistent
tile/layer data, collision queries, coordinate conversion and instance data.

## Status

`src/tilemap.kotoba` is the sole production source. Layers use a bounded sparse
representation: at most 32 occupied tiles per layer and 32 layers per tilemap;
invalid indices and capacity overflow fail closed. Clearing a tile releases its
sparse slot. Pure functions expose no IO/GPU effects.

Tests exercise the reference interpreter, restricted JavaScript target and
instantiated typed Wasm. Acceptance is observable value, rejection, typed-ABI,
effect and resource parity; generated byte identity is intentionally irrelevant.
