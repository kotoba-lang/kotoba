# Empty record emitter qualification

The published Sema options-map-argument floor accepts zero-field nominal records.
Script previously rejected their type descriptors, causing the published Amu JS
route to exit 70 without an artifact. Accept empty field vectors while preserving
qualified nominal IDs, unique fields, the 32-field ceiling, type depth/node bounds,
and boundary nominal/arity validation. Enable the empty record runtime codec only
when the checked module contains an empty record descriptor. Unaffected modules
retain identical generated bytes.

The registered Node fixture covers constructors, boundary cloning, wrong nominal
IDs, missing/extra values, nested records, typed capability arguments/results and
malformed schemas. Native record IDs and field keys retain their leading colon.
The 1,000-call fixture uses explicit fuel 10,000; default budgets are unchanged.

Local bootstrap qualification: 11 maintained scripts, 26 tests / 172 assertions,
109 parity checks, and 66 byte-identical goldens totaling 4,223,966 bytes. Forbidden
JVM launchers were shadowed and no marker was written. The same added fixture on
published ed36 ran 3 tests / 6 assertions with 2 errors at the old nonempty-field
validation. The candidate fixture ran 3 / 7 with zero failures/errors.

The tests used an explicit closed classpath and pinned nbb bootstrap engine, not
the standard peer-verifying wrapper: local sibling Git heads differ from its
pins. The new fixture is registered in that maintained wrapper. GitHub Actions
permissions were read back as disabled; no CI result is claimed.

Published Sema/Osaho plus candidate Script directly emitted the checked empty
constructor fixture. Its artifact ran on offline, read-only, nonprivileged Node
v24.21.0 in 1,000 fresh instances. This is direct pipeline qualification, not a
published normal Amu consumer result. Amu a060 still pins Script ed36 and refuses
the fixture. Advancing and qualifying that consumer is separate work.

This change was operator-authored. No System One model attempt or performance
score, native selfhost, browser execution or complete package migration is claimed.
Initial operator test mistakes (colon ABI, explicit fuel and effect grants) were
corrected before the final run; they are not model failures. See receipt.json and
retained logs for the stage-specific counts.
