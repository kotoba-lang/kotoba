# Native DEFLATE canonical Huffman reader — 2026-11-15

`deflate.huffman-reader/decode-symbol` builds canonical code counts from caller-supplied lengths, rejects empty, invalid-length and oversubscribed trees, and decodes one symbol from the bounded LSB-first bit reader using DEFLATE's MSB-first Huffman-code order. It returns the next bit offset only on success. This primitive permits incomplete trees; callers must enforce format-specific incomplete-tree and end-of-block rules. It does not construct dynamic trees, expand LZ77, verify zlib checksums, or decode an entire stream.
