# Native DEFLATE alphabet admission — 2026-11-15

`deflate.dynamic-tables/read-tables` now requires a complete code-length alphabet, and a complete literal or distance alphabet unless the latter is a permitted single one-bit symbol. The existing one-zero-distance-code case remains admitted for a literals-only block. Oversubscribed and empty code-length alphabets remain rejected, and a literal end-of-block code remains required. This follows the alphabet distinction used in zlib's `inflate_table` (`inftrees.c`, checked 2026-11-15): https://github.com/madler/zlib/blob/develop/inftrees.c. The primitive `decode-symbol` remains usable with incomplete alphabets, while this DEFLATE-specific admission is enforced by the dynamic-table parser.
