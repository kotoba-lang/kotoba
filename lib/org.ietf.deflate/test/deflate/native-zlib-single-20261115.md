# Native zlib single-dynamic-block profile — 2026-11-15

`deflate.zlib-single/inflate` is an explicitly limited RFC 1950 reader: it admits CM=8, CINFO=7, valid FCHECK, no preset dictionary, and exactly one final dynamic-Huffman DEFLATE block. It applies the existing output/work limits, requires the bitstream to end at the four-byte trailer, and verifies Adler-32. Other window sizes, dictionaries, fixed/stored or non-final/multiple blocks are rejected, not silently decoded. The 4,096-symbol and 1 MiB limits of `huffman-block` remain in force. This is not a general zlib implementation.

On macOS arm64 the pinned Native unit artifact refused truncated header, invalid FCHECK, unsupported window, dictionary, stored block and non-final block.
