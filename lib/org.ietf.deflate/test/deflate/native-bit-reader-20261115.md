# Native bounded DEFLATE bit reader — 2026-11-15

`deflate.bit-reader/read-bits` reads RFC 1951 LSB-first data elements from a caller-owned byte vector with explicit bit offset and width. The result includes the next offset only on success. It rejects negative or excessive bounds, width over 24, truncated input, and out-of-range bytes actually read; `align-byte` rejects offsets beyond the input. It does not decode a Huffman tree, a DEFLATE block, a zlib header or checksum.
