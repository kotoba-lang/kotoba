# Native dynamic DEFLATE tables — 2026-11-15

`deflate.dynamic-tables/read-tables` takes an offset immediately after BFINAL/BTYPE and reads bounded HLIT, HDIST and HCLEN fields, the code-length alphabet, and the combined literal/distance lengths, including repeat symbols 16–18. It rejects out-of-range literal count, invalid or oversubscribed alphabets, a missing end-of-block code, a repeat without a previous value, repeat overflow and truncated input. It accepts the RFC literals-only single zero distance alphabet. The existing Huffman length validator allows incomplete trees: callers must still enforce the format-specific incomplete-tree rules before using the returned tables. This is a table parser, not an inflater or checksum verifier.
