# Native Forest verified retry, 2026-11-14

`publish-verified-retry` calls the existing no-replace publisher. If it returns 95, the candidate and existing target manifests and all expected Pack files are compared byte-for-byte, using bounded source reads. Status 98 means these files matched during the observation; 99 means they differed or their metadata could not be read. The returned path remains the candidate staging directory in either case, so the caller can account for it. A provider trap can terminate the process instead. The comparison covers expected files, not unlisted directory entries. It does not authenticate the target, establish durability, or protect against concurrent edits or path replacement between checks; callers need separate authority and exclusion.
