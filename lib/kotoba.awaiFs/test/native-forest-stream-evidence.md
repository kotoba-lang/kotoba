# Native per-frame construction of a 16 MiB Forest Pack, 2026-11-14

`awai.fs.forest-stream` exposes bounded CARv1 Pack root/header and block-frame construction using the existing canonical DAG-CBOR/CID primitives and restricted Native Zstd raw/RLE writer. `checked-block-frame` checks the caller's previously fixed raw CID against the supplied leaf bytes before framing; the caller must own the buffer and prevent concurrent mutation during the call. These functions do not provide file I/O, source snapshots, an atomic root, WAL or durability.

A synthetic Native program first derives 16 leaf CIDs, constructs the canonical Pack root and header frame, then constructs and writes 16 individually framed 1 MiB leaves, the root frame and the Forest index/footer using bounded FS2 B/C requests and a per-leaf arena scope. It retains a CID/offset table, not the full 16 MiB logical input. The fixture leaves contain distinct leading bytes followed by zeros; the resulting Pack is 2,098,986 bytes. This is a demonstrator, not yet a general input streaming or allocation-bound proof. Native checks rejected a mismatched fixed CID, empty root input and unsupported codec.

On macOS arm64 `native_forest_stream_gate.sh PINNED_AMU NEW_OUTPUT` used pinned signed compiler/packager and KSL1 source locks. A separately compiled and separately launched Native reader opened the generated archive and verified all 16 leaf CIDs and every byte; a corrupted footer was refused. Fresh `.agent-output/native-stream-pack-04` passed. Native output SHA-256 `2e573d81d3edbf193b3d916eb7c166417105e4b852cc14135a74c47397073a05`; writer source lock `3f251c345ed176d7060fce46dbee605093e262910bd7cb61048a0c96f24907c5`; reader source lock `0c613f675fc076ec907ec8267969104f02da3f35e66acfd276f386a515b03a0b`.

Separately a one-time Babashka 1.12.218 Otehon `forest/verify-file` invocation checked the complete Pack, its header, all frame/block CIDs, all index candidates and the root. Independently regenerated 16 MiB expected bytes had SHA-256 `adf08d23b2abd50132d3a359ed3dae69fc39a47c335c6e9f80f9433c228179f8`, matching the decoded data; root CID `bafyreib4h2aen7nwokszeyxtpr23fga5ayporhsvqyfdumzlxjx6gbcdh4`. The Otehon oracle is not in the Native gate, build or execution path.

This local highly compressible fixture is a single Pack, not a GiB Native writer, general compression or throughput benchmark. The output file is written in place into a fresh test directory with no demonstrated fsync, atomic multi-Pack root, crash/OS-cache-loss recovery, authenticated catalog, safe concurrent truncation, or production qualification.
