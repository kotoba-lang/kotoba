# Native construction of a 17-Pack logical file, 2026-11-14

A synthetic Native test program uses `forest-write/encode-large` to construct 17 Forest Packs, each containing one distinct 1 MiB deterministic nonuniform leaf. For each chunk it derives the raw CID and logical-file row, writes the Pack through bounded FS2 B/C pieces, then writes a canonical Kotoba logical-file v1 manifest for 17 MiB. The program uses a separate arena scope per chunk. Its files are a fixture, not a crash-safe catalog or a general source-file import interface.

`native_forest_many_gate.sh PINNED_AMU NEW_OUTPUT` compiles and runs the Native writer with pinned signed macOS arm64 compiler/packager and KSL1 source lock. It compiles a separate Native reader using the independently checked manifest CID and a pinned physical-size vector. In a fresh process that reader checks the manifest, finds each chunk across all 17 files, verifies every chunk CID/length and the complete logical SHA-256. This is 17 MiB on local macOS, not GiB-scale Native writing, production admission, OS-cache loss, hardware power cut, concurrency safety, independently trusted metadata, or Native atomic multi-Pack publication. FS2 writes and the final manifest have no demonstrated fsync, WAL or atomic root; a failure can leave partial files. No throughput claim is made.
