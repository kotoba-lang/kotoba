# Native Forest v1 index writer, 2026-11-14

`awai.fs.forest-index-write/encode-index` builds the Forest v1 skippable index and footer for 1–64 caller-supplied CIDv1/raw-or-DAG-CBOR/SHA-256 IDs and frame offsets. It validates bounded inputs, uses one bucket with bounded linear probing, groups equal hash values, and appends the required empty sentinel. The one-bucket layout favors a simple bounded first implementation, not speed or compactness. It produces only index/footer bytes; it does not construct Zstd frames, CAR data, root blocks or a durable file/catalog transaction.

On macOS arm64, `native_forest_index_write_gate.sh PINNED_AMU EXTRACTED_2PACK PINNED_NATIVE_READER NEW_OUTPUT` compiled the canonical `.kotoba` source with pinned signed Native artifacts and a source lock. No host decoder participated in this gate.
