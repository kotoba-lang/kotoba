# Native bounded Zstd raw/RLE frame writer, 2026-11-14

`zstd.frame-write/encode-frame` creates a Zstd single-segment frame with an explicit four-byte content size, no dictionary/checksum, and blocks of at most 128 KiB. Each all-equal block of at least two bytes uses RLE; other blocks are raw. It accepts up to 2 MiB of bytes, rejects out-of-range elements and over-limit input, and emits a valid empty frame. This is a restricted frame encoder, not a general entropy compressor or a complete Forest writer. Format reference: RFC 8878 sections 3.1.1.1–3.1.1.2, https://www.rfc-editor.org/rfc/rfc8878.html.

On 2026-11-14 macOS arm64, `native_zstd_frame_write_gate.sh PINNED_AMU NEW_OUTPUT` verified pinned signed compiler/packager, built the canonical `.kotoba` source with KSL1 source lock, and ran Native writer plus Native frame decoder. It passed empty, one-byte, 255, 256, 131,072, 131,073 and 2,097,152-byte cases, raw/RLE, invalid element and over-limit refusal. Native wrote separate empty, raw and RLE frame files. Source-lock SHA-256 `2540463d4eac1cfc5c79fef3f0a9c0451643791e01165a4e1d9ccd5357e49303`; signed executable SHA-256 `710fdbedc24e655d308429c71331626cba047320507ac397b818519d7d7190ad`.

Separately, on the same date, Zstandard CLI 1.5.7 ran `zstd -d -q -c` against each of the three emitted files; a one-off Babashka 1.12.218 oracle generated the deterministic expected bytes and compared all bytes. Empty decoded to 0 bytes; raw and RLE decoded to 131,073 bytes each, exact match. Stored frame sizes were 12, 131,088 and 17 bytes respectively. This hosted oracle is not in the Native gate, CI or execution path. Files and commands are preserved under `.agent-output/native-zstd-write-04`.

The restricted profile does not support entropy-compressed blocks, dictionaries or checksums and makes no general compression, throughput, atomic publication, OS-cache-loss, Native Forest interoperability or production claim. Forest integration requires CAR block/root construction, offsets, generated indexes, publication and recovery checks.
