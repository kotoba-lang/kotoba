# Native variable-size Forest staging, 2026-11-14

`awai.fs.forest-source-stage/stage` constructs fixed 1 MiB logical chunks and up to 16 chunks per Forest Pack, for an explicitly supplied length from 0 through 1 GiB. The caller must supply an exclusive, empty staging directory prefix and ensure that its source and destination do not overlap. The supplied length defines the bytes to read; this function does not establish that it equals the source file length. It reads each chunk twice and checks the second read against the first CID. It returns a status and writes a manifest in staging only after all Packs have been written. Existing files in that directory may be overwritten. This is an uncommitted staging primitive, not a general-purpose atomic writer, source snapshot, WAL, fsync, fencing, or root publisher.

The Linux aarch64 Native selfhost compiler and provider pinned by `native-inputs.json` compiled `native_forest_source_stage_smoke.kotoba` with guest-specific paths. The test rejected a negative size, size above 1 GiB and a prefix without trailing slash; it returned Native result 0 for an empty file, 1 byte, 1,048,579 bytes and 16,777,219 bytes. The latter crossed a Pack boundary and had a 3-byte final chunk. A task-owned source comprised 16 MiB of random bytes and `xyz`, SHA-256 `f8b19f9def6dc033fedaf9a84c0f472396e056aac5bc150db9d6a469e277344b`. The outputs were respectively 0, 1, 1 and 2 Pack files. Native artifact SHA-256 `563d1926776db2cdb70138c10ee708509c46b1f770a4052f32863f76987fe817`; source lock `772f56e86e529e0d6b2a6f482636ed5ca3b7eed89a28dc86065669980bbbb19f` included guest-specific paths.

As a separate local Babashka/Otehon oracle, `oracle_native_source_stage.clj` imported the three nonempty staged groups and compared every recovered byte against the original source prefixes. All passed. The empty case verified manifest creation and zero Pack files; it was not independently imported. The oracle is not part of the Native build, gate or fallback. Input, Pack files, Native artifacts and oracle stores are retained under task-owned `.agent-output/native-stage-evidence` and the dedicated guest. The experiment makes no crash-durability, performance, production authority or physical power-loss claim. A missing or short source can cause the provider to terminate the process with `:fs/range-unavailable`, leaving partial staging files.

A subsequent Linux Native run added `regular-size` admission using FS2 O metadata. Before creating staging files, `stage` now requires a regular file whose observed size equals the supplied size and is at most 1 GiB. The updated smoke passed for independent files of 0, 1, 1,048,579 and 16,777,219 bytes; every staged byte matched the preceding run. A declared-length mismatch and a directory were refused with status 2, and neither requested destination existed afterward. Native artifact SHA-256 `765185c93b9a820a90a2cd91ecce8b3b6d3036fb8ee97b49cfbffd90f0410474`; guest-specific source lock `2a65230ab5a961eb5c522da8b9f538560fd223879f06807420b0f539d5ad2bf7`. This point-in-time preflight does not hold an open source or establish consistency when it changes later. The earlier test used one common source and declared prefixes before this check existed.
