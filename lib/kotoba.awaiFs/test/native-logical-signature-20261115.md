# Native Kotobase logical-signature v1, 2026-11-15

`awai.fs.logical-signature` emits the domain-separated Kotobase logical-signature v1 payload and verifies Ed25519 using `ed25519.selfhost`, including its prime-order public-key check. The supported subset is a 64-character lowercase hexadecimal logical root and nonempty ASCII issuer/key identifiers from letters, digits, `.`, `_`, `-`, `/` and `:`; other valid identifiers are explicitly refused. The caller must independently bind the public key to the issuer and key ID and validate the logical commit content and its root.
