# Native logical commit root and fixture basis, 2026-11-15

`logical-commit/root` parses a restricted observed v1 commit representation, canonicalizes the fields in Kotobase logical-domain order, and SHA-256 hashes the bytes. It accepts the fixed observed EDN field order, safe unescaped ASCII strings, a nonnegative JavaScript-safe epoch and zero parents. Other legal v1 presentations, one-parent commits, merge v2, escapes and non-ASCII are not implemented and are refused. It is not a general EDN or full Kotobase identity implementation.

`basis-verify/verify` composes the bounded proof-envelope reader, canonical commit root comparison, exact caller-supplied issuer and key-ID comparison, and Ed25519 verification with the caller-supplied trusted public key. It does not establish the trust of that key, verify a parent chain, establish the claimed checkpoint or policy, authenticate the separate physical-root/catalog, or enforce policy.
