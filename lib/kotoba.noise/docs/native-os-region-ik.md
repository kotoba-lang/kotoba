# OS region IK integration — JUN-757

`kotoba/noise/ik_region.kotoba` implements `Noise_IK_25519_ChaChaPoly_BLAKE2s` with the previously qualified region hash/HMAC, shared region AEAD and unchanged OS X25519. The existing vector NN/XX/IK/XXhfs and SHA256 APIs remain. This explicit OS path does not import the vector graph that refuses `sha2.core/s2-k`.

The caller owns8192 bytes:4096 active state plus4096 transient transaction storage. Before `initialize(state,length,initiator,bound)`, write the32-byte static private key at160, ephemeral private key at224 and remote static public key at288. Supply fresh ephemeral entropy; this API does not generate or attest randomness. A bound peer snapshots the expected static key and rejects a different decrypted peer before delivering its payload. Unbound mode is raw protocol computation, not admission. An initiator still supplies the responder static key; an unbound responder may start without an initiator static key. A signed roster, device identity, key custody, fresh operation consent and endpoint policy remain caller responsibilities.

After initialization, stream prologue bytes and call `prologue-finish`. `set-length` selects payload length for write and complete wire length for read. `write-message`/`read-message` take the complete state, actual input capacity and actual output capacity, with disjoint, immutable input buffers. Return-1 means refusal; authenticated empty plaintext returns0. Both65535-byte handshake envelopes are supported: first payload<=65439 and second<=65487. Empty messages also work with zero-length input/output slices and exactly96/48-byte wire buffers. Inputs and outputs are capped at65536 actual bytes; this is a memory bound, not a claim about UDP fragmentation or the product network driver.

`prepare-write`/`prepare-read` split tokens from payload processing. Current `h` is exposed for payload signatures; prepared reads accept exact32/80-byte token-only buffers, then bind all token bytes to the subsequent complete message. `get-byte` kind0 reads current h; kinds1/2/3 expose remote static/TX/RX only after status3 (complete). No peer/admission decision follows from the current transcript alone. Repeated, wrong-turn, malformed, undersized, oversized and post-completion operations refuse. Failed messages preserve active state and output; transient storage is erased. Valid initialized state has zero transient storage, so full-state failure snapshots also match. `wipe` clears all8192 bytes, including both hash workspaces through the canonical hash wipe operation. Calls must be serialized; inputs must remain immutable through authentication and decryption. This is not a constant-time qualification or authenticated persistence format.

The active layout is internal to this ABI: header0..63, h64, ck96, k128, s.priv160, s.pub192, e.priv224, e.pub256, rs288, re320, TX352, RX384, expected peer416, DH448, X25519 scratch512..1157, hash1280..1791, AEAD1792..2303, HKDF temporary2304..2367, encrypted static2368..2415, base point2432 and prepared prefix2560..2639. No heap, memory grant or compiler code limit is enlarged.

The source-locked18-module kernel keeps the actual ValueRuntime exports, two PT_LOAD segments (RX593024B and RW2359296B), the2MiB generated-code cap and the existing user-v5 domain request allocation. Native kernel/EFI/user ELF/slot reproduce. User code is not executed. The NIC-less QEMU fixture uses two8192-byte states, a separate failure snapshot and three64KiB IO buffers inside the existing256KiB request region. Public vector data occupies a checked zero tail of the pinned font; its header/glyphs/firmware are preserved.

`tools/ik_region_reference.py` reads the full six-profile vendored Cacophony inventory with a strict data reader and selects the exact IK/BLAKE2s profile. Independent RFC7748/RFC8439 references plus hashlib/HMAC reproduce both complete handshake messages, final hash and all four published transport ciphertexts. It also creates public varied-key fixtures: empty,1/15/16/17/63/64/65/257/1024/4096 and maximum payloads, plus prologues through65536 bytes. Python emits public test data only, never language source, kernel, ELF, EFI or media formats.

`tools/ik_region_gate.kotoba` executes13 handshakes, automatic and prepared forms, both bound and raw/unbound roles, full-state/output refusal snapshots, every byte of both first-message tags and the response tag, wrong bound peer, zero ephemeral point, prepared-prefix replacement, wrong turns, invalid lengths/aliases/short buffers, maximum+1 refusal, early peer/key access, post-completion reuse and full wipe. It independently records95 values:91 wire hashes/transcripts/TX/RX fields and four transport hashes. For the four published post-handshake messages it compares every ciphertext byte, decrypts in both directions using the derived peer keys and refuses a tampered tag without output writes. This is actual component encryption/decryption, not a datagram socket, replay-window or clock-lifetime qualification.

The receipt `docs/evidence/kekkai-native-20261102/os-region-ik.json` contains normal and fault-injected results. A compiler refusal from an initial fault that removed a helper's sole call is retained as a failed test attempt; comparison faults keep the helper calls and must complete normally to count. Initial E7106 failures are not acceptance evidence.
