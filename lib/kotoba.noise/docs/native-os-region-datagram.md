# OS region datagrams — JUN-757

`kotoba/noise/datagram_region.kotoba` adds an allocation-free OS counterpart to the existing vector `noise.datagram` API. The vector implementation remains unchanged. Both use `counter:u64le || ChaChaPoly ciphertext`, with the eight header bytes as associated data, at most 65,511 plaintext bytes and a 65,535-byte complete envelope. An authenticated empty plaintext returns 0; refusal returns -1.

The caller owns 17,408 bytes. `from-handshake(state,actual-state-capacity,handshake,actual-handshake-capacity,expected,actual-expected-capacity,now)` requires at least 17,408/8,192 bytes, exactly 32 expected-key bytes, a complete `noise.ik-region` handshake, a matching remote static key and a nonnegative clock. The output state must not overlap the consumed 8,192 handshake bytes or the 32 expected-key bytes. Read-only inputs may overlap. Supplied lengths describe actual admitted regions; checked subregions establish the fixed internal extents after the size checks. Invalid construction preserves the destination and its inputs. The caller must obtain the expected key from a verified roster. Comparing it does not verify that roster, grant admission or turn peer-supplied data into authority.

`set-length(state,actual-capacity,n)` selects plaintext length for `seal`, or complete wire length for `open`. The message operations take `(state,input,actual-input-capacity,output,actual-output-capacity,now)`. State is an already admitted full 17,408-byte region. Input/output capacities are bounded by 65,536 bytes and all writable regions must be disjoint. Calls must be serialized and inputs immutable throughout authentication and decryption. Shape refusals occur before scratch writes. API-created states have zero transient storage; all other refusals preserve that entire state and output, including erasing the transient AEAD workspace after bad authentication. No plaintext is written before the complete tag is authenticated.

The internal layout is magic at 0; send counter 8; receive maximum 16, initially -1; birth/last-successful clock 24/32; accepted count 40; logical length 48; layout version 56; TX/RX bytes 64/96; 2,048 u64 replay markers at 128..16,511; AEAD workspace at 16,512..17,023; authenticated peer at 17,024 and handshake hash at 17,056. Remaining padding is zero. This is an internal region ABI, not an authenticated serialization, backup or user-editable session format. `wipe` erases all 17,408 bytes, and invalid/wiped state refuses messages.

A slot contains `counter+1`; zero means unseen. Authentic reordered packets within 2,047 of the high watermark are accepted. A packet at `maximum-2048` or older refuses. Only successful authentication changes the maximum, slot, accepted count and last clock. Header high bytes are checked before decoding, so an arbitrary u64 cannot become a negative index or overflow a signed counter calculation.

`advice(state,actual-capacity,now)` returns 0 for current, 1 for rekey requested, or 2 for refusal/expiry. It never mutates state. Backwards clocks, age at least 180 seconds, or send/accepted counts at least 9,007,199,254,740,990 refuse. Age at least 120 seconds or a send counter at least 281,474,976,710,656 requests rekey while still permitting traffic below the expiry limits. Clock arguments are integer seconds from a trusted monotonic source; this component does not provide or calibrate that source. Clock and large-counter boundary fixtures are synthetic inputs, not 180-second live sessions or 2^53 actual transmissions.

Construct a session once from each fresh authenticated handshake. Never reconstruct an old handshake to reset counters under the same keys. Fixture resets deliberately reuse public test keys; they are not an approved production lifecycle. The caller must supply entropy, fresh key exchange, verified roster/version and revocation handling, close/wipe expired or revoked sessions, and enforce trusted operation consent. Sessions and approvals must not be restored from ordinary app state.

`tools/datagram_region_gate.kotoba` performs a real public Cacophony IK handshake: a bound initiator, raw responder, prepared first-message tokens read separately, and an automatic second message. It compares all saved first-message tokens and records both handshake wire hashes, transcript and directional keys. Both endpoints then construct datagram states with mandatory expected-peer matching. Short regions, wrong peers, incomplete handshakes, aliasing and invalid clocks refuse without changing destination state.

The native fixture covers both directions at plaintext lengths 0, 1, 15, 16, 17, 63, 64, 65, 257, 1,024, 4,096 and 65,511. Maximum frames use exact 65,511/65,535-byte physical views. It also generates 2,048 distinct empty frames, hashes their complete concatenation, receives all in reverse order, checks every slot and rejects all 2,048 repeats without state/output changes. It tests circular rollover, the exact 2,048-old boundary, all 16 tag positions, changed ciphertext/header/key, high unsigned header values, failure not advancing clock/replay, successful final counter/count operations, both directions of expiry/backwards-clock refusal, exact rekey boundaries, full wipe and post-wipe rejection. Six independently authenticated packets at forbidden counters ensure range refusals are not merely tag failures.

`tools/datagram_region_reference.py` uses the existing independent RFC7748/RFC8439 references and hashlib/HMAC to reproduce the checked IK split, all datagram ciphertexts, the complete 2,048-frame stream hash and synthetic large-counter frames. It emits public bytes only. The original 7,232-byte IK corpus plus six padded forbidden frames occupy 7,424 bytes in a checked zero font tail at 393,216..400,639; the font header, glyphs and all bytes outside that tail remain unchanged. The native log has 39 complete 32-byte records, compared in full on the host.

The 19-module kernel retains the actual ValueRuntime export graph, two PT_LOAD segments (RX 653,568 bytes; RW 2,359,296 bytes), the fixed 2 MiB generated-code cap and existing memory grants. Two states, a complete failure snapshot and three 64 KiB IO buffers fit in the existing 256 KiB domain request region. Handshake copies share unused input space until the final maximum-frame test. Native Amu emits and reproduces kernel/EFI/user ELF/slot; the diagnostic user code is not executed. Python stages/hashes/observes and supplies independent public expected data; it is not a compiler, crypto runtime or fallback. QEMU has no NIC and does not alter the fixture medium.

`docs/evidence/kekkai-native-20261102/os-region-datagram.json` retains the final positive, separately compiled normally completing faults, exact source/artifact pins and regressions. Initial provenance refusals are failed attempts, never successful negative controls.
