**Status: R2**

`cloud-itonami-isic-5320`（コミュニティ・ラストマイル配送）向けの capability

## 触るときの注意（実測で分かっていること）

- **営業時間の window は `open > close` で日跨ぎを意味する**（22:00–02:00）。
  2026-08-04 まで `open < close` を要求しており、**居酒屋・コンビニ・深夜薬局を
  そもそも表現できなかった**（`store` が構築ごと拒否していた）。
- **`open-at?` は前日の日跨ぎ window も見る。** 金曜 22:00–02:00 の店は
  土曜 01:00 に開いている。ここを片方だけ実装するのがこのバグの典型形で、
  hours テーブルは正しく見えるのに**その店が一番忙しい時間帯だけ閉店**と判定される。
- **`"24:00"` は 1440 として受理する**（締め時刻の一般的な書き方）。ただし
  24:00 に「開店」はできず、`24:30` は不正のまま。`open = close` は 0 分とも
  24 時間とも読めるので拒否する。
- **`export/json-str` は U+0020 未満を全てエスケープする**（RFC 8259）。旧実装は
  backslash / quote / `\n` だけを見ており、スプレッドシート由来の店名にタブや CR が
  混ざると**どのパーサも受け付けない JSON** を出していた。
